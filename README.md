# Defense presentation

Browser slideshow: https://slides.ziqguo.com/

Direct slide links use one-based numbers, for example `/#/16`.
Use the arrow keys or buttons to navigate, the slide number field to jump,
and the Slides button for thumbnails. Press F for fullscreen. On touch devices,
swipe horizontally to change slides. Click Play video on slides 6, 19, and 26.

The viewer includes all 81 slides (71 main slides and 10 appendix slides).
Slide images render at 2560 × 1440. The three original embedded videos play
in their slide positions. PowerPoint object animations and transitions are
represented as static rendered content; use the original PPTX for native
PowerPoint behavior. PDF and PPTX downloads are available in the toolbar.

This is a static site with no external JavaScript dependencies. Publish the
repository root through GitHub Pages. Preserve CNAME for slides.ziqguo.com.
